# Simple Resume Website

A clean and responsive single-page resume website built using **HTML5** and **CSS3**. This project is designed to practice semantic HTML, structured content, CSS styling, Flexbox, CSS Grid, and responsive web design.

## 📌 Project Overview

This website presents a professional online resume containing:

* Profile / Introduction
* Education
* Skills
* Work Experience
* Projects
* Contact Information

The design is simple, professional, and easy to scan on both desktop and mobile devices.

## 🛠️ Technologies Used

* **HTML5** — For the structure and semantic content
* **CSS3** — For styling and responsive layout
* **CSS Grid** — For skills and project layouts
* **CSS Flexbox** — For navigation/contact information and alignment
* **Media Queries** — For responsive design

## 📂 Project Structure

```text
resume-website/
│
├── index.html
├── style.css
└── README.md
```

### Files

**`index.html`**

Contains the complete structure of the resume website, including the profile, education, skills, experience, projects, and contact sections.

**`style.css`**

Contains all styling rules, including colors, typography, cards, layouts, spacing, Flexbox, CSS Grid, and responsive design.

**`README.md`**

Provides information about the project, its structure, features, and how to run it.

## 🚀 How to Run

1. Download or clone the project.

2. Open the project folder:

```text
resume-website/
```

3. Open `index.html` in any modern web browser.

You can also use **Visual Studio Code** with the **Live Server** extension for easier development.

## ✏️ Customization

For example:

* Fonts
* Spacing
* Card styles
* Background colors
* Layout
* Responsive breakpoints

## 📱 Responsive Design

The website includes CSS media queries to adapt the layout for different screen sizes.

On smaller screens:

* Skill cards become a single column
* Project cards become a single column
* Text sizes are reduced
* Contact information is arranged vertically
* Content spacing is adjusted for mobile devices
